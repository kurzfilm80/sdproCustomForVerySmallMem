# GeekMagic SmallTV / Ultra CS15 pinout

| Function | Value |
| --- | --- |
| Firmware profile | `geekmagic_smalltv_cs15` |
| MCU | ESP8266 / ESP-12F |
| Flash | 4 MB, DIO, 40 MHz |
| Display | ST7789-compatible, 240 x 240 |
| SPI MOSI | GPIO13 |
| SPI SCLK | GPIO14 |
| Display CS | GPIO15 |
| Display DC | GPIO0 |
| Display reset | GPIO2 |
| Backlight | GPIO5, active LOW, PWM |
| SPI mode | 3 |
| Pixel order | RGB |
| Color inversion | Disabled |

Source: `giovi321/smalltv-mod`, original SmallTV / Ultra ESP8266 profile.
